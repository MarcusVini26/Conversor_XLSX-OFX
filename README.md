# Conversor_XLSX-OFX
Converte o relatório XLS de pagamentos SISPAG do Itaú em arquivo OFX individualizado por favorecido, compatível com importação direta no Omie. Resolve o agrupamento nativo do extrato OFX do Itaú, permitindo conciliação bancária automática. Interface gráfica inclusa. Suporta XLS e XLSX.
Projeto está no Beta.


Para gerar o executável, basta rodar o arquivo build.bat, ele vai compilar o código e gerar a pasta /dist e nela terá o executável.
